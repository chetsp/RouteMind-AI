# Evaluation review downloads

[Download the sample review ZIP](https://github.com/chetsp/RouteMind-AI/raw/refs/heads/main/docs/downloads/RouteMind_Policy_Review_Template.zip).

Extract the ZIP and open your reviewer HTML file in a browser. The pack contains offline retrieval-only samples and blank ratings, not completed human reviews or live-model answers. Regenerate it from live responses before conducting the live-answer study. See [the evaluation workflow](../../evaluations/quality/REVIEW_GUIDE.md).
